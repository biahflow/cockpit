# FDDs

Cada FDD descreve uma funcionalidade: o problema, o comportamento esperado, o modelo de dados, a API e os testes que a sustentam. Numere arquivos sequencialmente.

O índice abaixo é **derivado**: cada entrada repete, palavra por palavra, o `#` do arquivo, sem o prefixo `FDD NNN — `. Não anote, não encurte, não reescreva — o que o título precisa dizer, diga no `#` do arquivo, que é o único lugar onde ele vale.
