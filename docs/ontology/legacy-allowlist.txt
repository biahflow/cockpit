# Allowlist do vocabulário legado — dívida declarada, não permissão
# =============================================================================================
# Formato: <caminho relativo ao repo>::<id-da-regra>::<identificador>::<contagem>
# `#` comenta a linha inteira; linha vazia separa bloco.
#
# Cada linha aqui é um nome que o repositório ainda diz errado e que a guarda
# `backend/tests/test_vocabulario.py` (ADR 0049) deixa passar **por ora**. A lista nasceu com o
# estado de `main` @ 80da2a5 — exatamente as ocorrências que a guarda encontrava naquele commit,
# nem uma a mais — e três testes a mantêm honesta:
#
#   * `test_nenhum_termo_banido_novo` reprova o que não está aqui — e também a ocorrência **a
#     mais** numa chave que já está;
#   * `test_a_allowlist_nao_guarda_linha_desnecessaria` reprova a entrada maior que a dívida que
#     ela isenta, forçando a baixa do número — ou a remoção da linha, quando a dívida zera;
#   * `test_a_allowlist_so_encolhe` guarda o teto (`TETO_DA_ALLOWLIST` = 59), que conta **dívidas
#     distintas** — linhas deste arquivo, não ocorrências no código. Os dois números não medem a
#     mesma coisa.
#
# A entrada **não carrega número de linha**, de propósito: dívida declarada não pode ser reaberta
# por alguém ter inserido um import acima dela. Ela carrega a **contagem**, que é a outra metade
# da mesma decisão: sem o número, `models.py::client-como-organizacao::client` isentaria as doze
# ocorrências de hoje **e a décima terceira** — e `models.py` é onde todo modelo novo nasce.
# Medido por sabotagem (ADR 0027): um `client = models.ForeignKey(...)` acrescentado ao fim de
# `models.py` passava em silêncio na primeira versão desta guarda.
#
# Pagar dívida em parte **abaixa o número da linha**; pagar inteira **remove a linha**. As duas
# coisas são cobradas, e a mensagem do teste diz qual número escrever.
#
# Quem paga cada bloco está em `docs/ontology/aliases.md`. Resumo: renome físico é a Fase 6, a
# remoção do alias de rota é a `/api/v2/`, e o split Evidence/Finding é a Fase 3.
