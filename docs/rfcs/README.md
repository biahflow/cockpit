# RFCs

RFCs são obrigatórias antes de integrações externas, alterações incompatíveis de API ou mudanças transversais. Devem registrar motivação, alternativas, impacto, segurança e plano de migração.

- 0001 — Contrato e segurança da plataforma
- 0002 — Jornada de consultoria assistida por IA
- 0003 — Visibilidade de projeto por participação
- 0004 — Contas a receber e cobrança relacional (proposta)
